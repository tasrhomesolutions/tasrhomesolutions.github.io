# TASR Home Solutions website

Live at https://tasrhomesolutions.com, hosted on GitHub Pages from the `main` branch of this repo.

| File | What it is |
| --- | --- |
| `index.html` | The home page (exported from Claude Design, with the booking form wired up) |
| `privacy-policy.html` | Privacy Policy, including SMS opt-in wording |
| `terms.html` | Terms & Conditions, including SMS program terms |
| `assets/` | Logo, icons, share image and the stylesheet for the policy pages |
| `CNAME` | Tells GitHub Pages to serve the site at tasrhomesolutions.com |

Booking-form requests are emailed to office@tasrhomesolutions.com through FormSubmit (formsubmit.co).
The first request after going live triggers a one-time "Activate form" email to that inbox.
